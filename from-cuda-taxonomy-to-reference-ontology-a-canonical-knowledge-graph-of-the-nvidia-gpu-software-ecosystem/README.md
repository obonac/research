# From CUDA Taxonomy to Reference Ontology: A Canonical Knowledge Graph of the NVIDIA GPU Software Ecosystem

Academic research poster presenting a canonical reference ontology for the NVIDIA CUDA software ecosystem. The work organizes GPU hardware, runtime systems, compilers, numerical libraries, AI frameworks, communication layers, enterprise platforms, and scientific computing into a unified typed knowledge graph. The ontology defines semantic metadata, explicit dependency relationships, orthogonal graph projections, and executable graph traversals that enable reasoning, dependency analysis, semantic querying, impact analysis, version tracking, automated discovery, and engineering intelligence across the complete CUDA ecosystem. The framework demonstrates how layered taxonomies evolve into executable knowledge graphs supporting software architecture analysis, graph databases, formal ontologies, AI-assisted engineering, and knowledge-driven software ecosystem management.
